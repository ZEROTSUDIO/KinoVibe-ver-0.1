# KinoVibe Screenshots

Place your app screenshots in this folder to display them on the landing page!

Recommended filenames and resolutions (16:9 or 16:10 aspect ratio, e.g. 1920x1080 or 1440x900):

1. **`library.png`** (or `.jpg` / `.webp`)
   - Screenshot of the movie library grid with posters and tags.
2. **`review.png`**
   - Screenshot of the movie review/detail page showing sliders, backdrops, and bias modifiers.
3. **`tiers.png`**
   - Screenshot of the S-to-F tier rankings list.
4. **`matrix.png`**
   - Screenshot of the 2D Vibe Matrix (Quality vs. Entertainment scatter plot).

The landing page automatically looks for these files at:
- `screenshots/library.png`
- `screenshots/review.png`
- `screenshots/tiers.png`
- `screenshots/matrix.png`

Until screenshots are added, high-fidelity interactive wireframes are displayed automatically as fallbacks.
